# pilots-kainos-may-2026

This repository contains planning, activities, and outputs for the Kainos pilot work in May 2026.

Short pointers to key folders in this repository:

- [activities](activities/) - Pilot activity definitions and working notes.
- [artefacts](artefacts/) - Outputs and evidence produced during pilot work.
- [artefacts/templates](artefacts/templates/) - Reusable documentation templates for skills and agents.
- [dsit-legacy-risk-assessment-tool](dsit-legacy-risk-assessment-tool/) - Local copy of the risk assessment tool used in the pilot.
