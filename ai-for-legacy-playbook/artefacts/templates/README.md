# Reusable Templates for Skills and Agents

Use these templates when creating or updating documentation for reusable skills and agents.

## Templates

- `SKILL-README-TEMPLATE.md` - for skill docs.
- `AGENT-README-TEMPLATE.md` - for agent docs.

## Why these templates exist

They are written for mixed audiences, including non-technical users.  
Each template uses plain-language sections for:
- purpose
- when to use
- how to invoke
- expected output
- troubleshooting

## Minimum sections to keep

When you adapt a template, keep at least:
1. What this is for
2. When to use it
3. Before you run this
4. How to invoke it
5. Inputs
6. What you will get (output)
7. Example output
8. Guardrails/boundaries
9. If something goes wrong

## Adoption guidance

- Keep frontmatter/metadata currently used by the target skill/agent.
- Keep examples copy-paste friendly.
- Prefer short headings and short sentences.
- Avoid deep internal jargon unless you define it.
- Do not bulk-rewrite all existing artefacts in one change; update incrementally.
